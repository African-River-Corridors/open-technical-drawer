Open Technical Drawer (OTD)

The Drawing Format Standard in Rust. A drawing document goes in. Normalised content comes out, and from it SVG, PDF and DXF.

  • Version: 0.4.0
  • Standard: 1.2
  • Language: Rust
  • Licence: Apache 2.0

What it is

  • Domain-free. OTD knows sheets, viewports, entities, dimensions, hatches, the title block and the writers. It knows nothing about what is drawn. The tool that uses it owns its own checks.
  • Pure. The core opens no file, reads no clock and uses no network. It builds for WebAssembly.
  • The same on every platform. Every transcendental function goes through libm.
  • Checked against the standard. The standard's conformance suite is vendored, pinned by commit and hash. Every case must pass in CI.

Use it

OTD is not on crates.io. Pin it by git tag:

[dependencies]
otd = { git = "https://github.com/African-River-Corridors/open-technical-drawer", tag = "v0.4.0" }
let result = otd::run_text(&drawing_document_json, &otd::NoFiles);

run_text returns the normalised content, or the errors the standard defines. The writers are in otd::render: svg, pdf and dxf.

Standard versions

OTDDrawing Format Standard
0.1.x1.0
0.2.x, 0.3.x1.1
0.4.x1.2

Each version reads documents of its own minor version and every earlier one.

Who uses it

Open Vessel Designer (OVD) and Open Waterway Designer (OWD) draw their sheets with OTD.
